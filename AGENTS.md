# ReviewRadar
New Week 3 project, begun 23 October 2026. Scope: source-linked individual requests and possible later responses in selected authored public GitHub PRs. This is not a code-fix verifier or autonomous GitHub writer.
- Work only in this project; prior applications are reference, not source templates.
- Model suggestions, GitHub reported states, and human dispositions are distinct.
- Exact quotes and source IDs must validate against the bound snapshot. Model text is untrusted. No model-provided arbitrary links, commands, tools, or external writes.
- Fail visibly for incomplete intake or analysis. No falsely clean queue on error, truncation or no model.
- No secrets, model weights, downloaded runtimes, private inputs or raw credentials in Git. Free/local services only. Public fixtures need precise provenance and dates; never invent a human trial or time savings.
- Agents own explicitly delegated files; do not commit, publish, modify other modules, or stop unrelated processes. Parent integrates, reviews and releases.
- All meaningful implementation stages require appropriate regression checks and independent review. Test assertions must protect behavior, not mirror code.
