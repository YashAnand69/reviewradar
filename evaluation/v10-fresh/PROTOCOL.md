## Annotation and freeze

Read all eligible human sources in each selected PR before predictions. Mark distinct actionable asks, questions or specific defect reports; praise, thanks, generic agreement and closure are not separate asks. Mark optional suggestions as optional. Label exact request anchors, acceptable later author response IDs and exact anchor quotes, and note genuine ambiguity. An acknowledgement alone is not a relevant answer to a technical ask. A report of implementing/investigating the requested behavior is conversational evidence, not verification of correctness. No later relevant author passage means an expected null. Keep full public discussions ignored locally. Publish concise paraphrases, source IDs/links, capture dates, and hashes rather than redistributing long third-party text. Freeze hashes/timestamps before any inference. Parent reviews stage1 artifacts before allowing predictions. Do not alter labels merely to match output; document any legitimate scoring correction and preserve original labels.

## Frozen run and scoring

Run `human-review-passages-v10` once per selected complete snapshot against the existing local model, with no retries or best-of selection. Capture model.py and combined prompt hashes, model/runtime identities, configuration, case status and elapsed wall time. Compare the chronology baseline on identical snapshots; it is a reviewer reading list and does not perform request classification or response matching.

Manual semantic scoring matches meaning to frozen labelled asks, not exact extraction text. One card may cover multiple closely coupled requirements within one labelled ask; genuinely separate asks count separately. Each expected ask is found at most once. Redundant cards after a first match are duplicate extras; a card with no labelled ask is an extra. Count missing asks, covered asks, extras/duplicates separately. For matched cards, score accepted later author response, wrong response, expected-null respected, wrong-null omission, or ambiguity separately. Keep inference failure and incomplete coverage separate from semantic miss; report end-to-end missed asks including failed cases as well as successfully analyzed coverage. Validate exact source identity, quote, actor, chronology and bounds with the existing bound-analysis validator. Report all explicit denominators and latency; no single combined accuracy or benefit claim.

No semantic tuning belongs to this frozen experiment. A later model change makes exposed cases regression data; only a separately selected untouched set could support a fresh holdout claim. Category gaps, selection bias and assistant-only annotation remain visible.
