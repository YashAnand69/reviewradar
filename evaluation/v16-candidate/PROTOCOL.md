## Semantic scoring

Score against the existing frozen assistant annotations, unchanged. Source-ID overlap alone cannot establish that a selected passage expresses an action. Preserve partial/fragmented coverage, genuine compound requests, duplicate cards and context/non-request extras. Select the clearest nonredundant primary request representation before grading its reply; an extra favourable response cannot replace a primary's bad response. Multiple full asks can share one compound card, so report action coverage and primary-card denominators separately.

Read the selected author passage against the specific ask and source context, not just the response ID. The previously documented legitimate alternative generic-error response remains an explicit scoring addendum, not an overwritten label. Relevant conversation does not prove a code fix or maintainer satisfaction. A null reply on a false request is not a correctly absent reply.

The implementation/scoring agent is the same assistant in this study. Label creation and scoring are engineering judgements, not independent human adjudication. Preserve noted counter-readings, especially the coordinated-ownership objection, supportive comments and geometry grouping. Do not collapse heterogeneous sets into population accuracy or a user-savings claim.

## Decision boundary

The exposed Eventyay6104 ablation motivates investigating the extraction prompt; it does not establish this candidate's general superiority. Compare the20case results with their original version-specific results and report new material regressions. No default promotion follows automatically. A parent review must weigh missed asks, wrong/extra/duplicate cards, weak replies, failures and latency together. Any genuinely fresh evidence must be selected and frozen separately; these cases cannot become unseen again.
